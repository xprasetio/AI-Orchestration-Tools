# AI Orchestration Tools

A cyberpunk-styled landing page for an open-source AI orchestration control layer. Built with Vite, React, and TypeScript; deployed to GitHub Pages.

## Local development

```bash
npm ci
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Pushes to `main` automatically build and deploy the `dist/` output via GitHub Actions. Enable GitHub Pages in repository settings with **GitHub Actions** as the source if it is not already configured.

## Design direction

Cyberpunk / glitch interface: void-black surfaces, electric green/magenta/cyan accents, CRT scanlines, terminal typography, chamfered panels, subtle glitch animation, responsive layouts, and reduced-motion support.

## Status

Marketing copy and product capabilities on this page are an initial concept draft and should be adjusted to the actual product before launch.
